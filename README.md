# Sticky

Фиксированное позиционирование для основного заголовка, чтобы он оставался видимым при прокрутке.  

Это улучшает доступность навигации на длинных страницах.

Изменения включают:
- Применено CSS `position: sticky` с отступом сверху
- Добавлен лёгкий эффект тени при активации «прилипшего» состояния
- Отрегулированы отступы для предотвращения сдвига макета
- Обеспечена адаптивность для небольших экранов
- Оптимизирована производительность перерисовки при прокрутке

**BREAKING CHANGE:** Высота заголовка в режиме «прилипшего» состояния уменьшена,  
что может повлиять на макеты, которые полагались на прежнюю фиксированную высоту.
